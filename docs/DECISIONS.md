### D-027 — האתר נבנה מצילום מצב שמיוצא מהמסד (הוחלפה ב־D-028)
2026-11-01: האתר מפסיק לקרוא את content/*.json. לפני dev ו־build מריץ scripts/export-catalog.mjs שאילתות קריאה בלבד מול academy (טרנזקציה אחת, read only) וכותב את generated/catalog.json, שאינו נשמר ב־Git. src/data/catalog-export.mjs ממפה את הטבלאות לאותם מבנים שהעמודים צרכו (KnowledgeEntry, ToolFacts, AgentMetric ומדריכים), כך שהעמודים ורכיב הטבלה לא השתנו. ציון GitHub Interest מחושב מהמדידות של כל מדגם במועד האחרון שלו; Stars ופעילות בטבלה נלקחים מהמדידה האחרונה שתיעדה פעילות, כדי שמדידת מדגם בלבד לא תמחק את הפעילות. כל התאריכים מומרים ב־SQL כדי למנוע הסטת אזור זמן.

הגישה דרך role ייעודי academy_build_reader (מיגרציה 005): SELECT בלבד על טבלאות הקטלוג, policies שמציגות רק פריטים שפורסמו ושורות התלויות בהם, ללא גישה לתור המחקר, לטבלת sources או לארכיון. הסיסמה מוגדרת ידנית ואינה נשמרת במאגר. build נכשל אם המסד אינו זמין; dev ממשיך עם צילום המצב הקודם ומציג אזהרה. בדיקת PGlite משווה את הייצוא, כמשתמש הקריאה, לכל מבנה שהאתר בנה מ־JSON: התאמה מלאה למעט תיאור הקטלוג ב־7 פריטי 02, שמיגרציה 003 איחדה בכוונה לנוסח הקומפקטי (שדה זה אינו מוצג בממשק). content/*.json נשארים מקור ייבוא היסטורי וקלט לבדיקות, ל־metrics:refresh ולמחקר עד שיועברו למסד; אין לערוך אותם כמקור לאתר.

### D-026 — מקור פעיל יחיד לכל שדה וארכיון ייבוא נפרד

הסכמה הישנה שונתה ל־academy_import_archive, מוגנת מכתיבה, ומנותקת ב־FK מהנתונים הפעילים. היא נשמרת להתאוששות ולא לעריכה או לסנכרון. המקורות המקוריים והנתונים שלא מצדיקים מודל פעיל (כגון תיעוד ניסיונות מחקר כושלים) נשמרים בה במלואם. אין המצאת היסטוריית גרסאות; revision מתאר את הגרסה הנוכחית. audit עתידי יתווסף עם עריכה מקוונת. מיגרציות טרנזקציוניות בודקות התאמה לפני Commit; שחזור לשלב הקודם נבדק מקומית בלי למחוק נתונים. 30 בדיקות עברו ואימות SQL בענן אישר שלמות, היעדר JSON בטבלאות ו־RLS בכל הטבלאות. אין עדיין חיבור אתר למסד או הרשאות קריאה חדשות; D-002 מתארת עדיין את מסלול הקריאה הפעיל של האתר. מפת השדות ב־[DATA_DICTIONARY.md](../database/DATA_DICTIONARY.md).
