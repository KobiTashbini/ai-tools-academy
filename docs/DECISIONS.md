## אימות נקודת הייחוס
LinguaReader נבדק בקריאה בלבד ב־main, commit 0cdbbd2ecae79bcdd0bd4599d0fb7b44018ae33d. אומתו Next.js 16.3.3, React 19, TypeScript strict, Route Handlers, REST ל־Supabase, RTL ו־Demo Mode המתואר ב־README. מצב פריסות, חשבונות ותשלומים לא אומת. לא מעתיקים קוד, מפתחות או נתוני ייצור.
