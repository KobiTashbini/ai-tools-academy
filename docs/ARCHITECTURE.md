> סטטוס: **תוכנית V1 אושרה ב־2026-10-31**. מימוש מקומי מאושר; שירותי ענן ופריסה דורשים אישור נפרד. ההחלטות המחייבות מתועדות ב־DECISIONS.md.

## המימוש הנוכחי
סביבת הפיתוח כוללת הפעלת Debug אופציונלית עם Webpack לשרת Node.js דרך `npm run dev:debug` והגדרת F5 ב־VS Code. עמודי האטלס נשארים Server Components; ניפוי קוד שרת דורש חיבור ל־Inspector המקומי, בנפרד מ־DevTools של לשונית האתר. הוראות ב־README.

תצוגת רשימת כלים בכל קטגוריה משתמשת ב־ToolCatalog משותף: טבלה כברירת מחדל, כרטיסיות אופציונליות, מיון והרחבה מקומית באמצעות React state. עובדות טבלה ו־GitHub נשמרות כצילום מצב JSON ונבדקות בטעינה. אין קריאות לספקים מתוך הדפדפן; מקור ושיטת המדידה מפורטים ב־[METRICS.md](knowledge/METRICS.md).

Next.js + React + TypeScript, תוכן JSON מקומי תחילה, ללא מסד נתונים או API נוסף. עמודים נוצרים סטטית בעת build. src/domain מגדיר את מודל הידע; src/data בודק וטוען את התוכן ומסנן פריטים שאינם מפורסמים; src/app מציג בית, אטלס, קטגוריה ופריט. 12 הקטגוריות שומרות על מזהי 00–11. המקורות ותאריכי האימות נשמרים עם הפריט. תוכן Markdown וראיות מפורטות יותר יתווספו בהמשך. החלופות להלן נשמרות כרקע להחלטה.

## נקודת ייחוס: LinguaReader
מאגר: https://github.com/KobiTashbini/lingua-reader

קובצי הפרויקט שנבדקו מצביעים על:
- Next.js 16 + React 19 + TypeScript, Node.js ו־npm.
- API Routes בתוך Next.js.
- Vercel לאירוח, Supabase (PostgreSQL) לאחסון נתונים.
- OpenAI API.
- הגדרות מקומיות דרך `.env.local` והפעלה ב־`npm run dev`.
- אפשרות Demo Mode ללא חיבורי Supabase/OpenAI לפי README.

**ההגדרות בקוד אינן מוכיחות שמנוי ענן או פריסה מסוימת פעילים ברגע זה.** על Codex לבדוק את המצב בפועל דרך ההרשאות הזמינות; לא לבקש סודות בצ'אט.

## החלטת V1
Next.js + TypeScript (React) עם תוכן מקומי תחילה. אין צורך ב־API פנימי לקריאת קובצי התוכן. Supabase נדחה; Vercel מועמד לפריסה עתידית באישור נפרד. החלופות נשמרות כרקע להחלטה ולבחינה עם שינוי הדרישות.

### חלופות שיש להשוות
- Next.js עם תוכן Markdown/JSON סטטי תחילה ורק לאחר מכן Supabase.
- Next.js Frontend + ASP.NET Core API נפרד (אם יש הצדקה עסקית/תפעולית).
- Background Worker ב־TypeScript, C# או Python בשלבי העשרת הידע.
- פתרון חלופי ש־Codex מצא מתאים יותר על בסיס יתרונות וחסרונות מוכחים.

## גבולות מערכת לוגיים
1. **UI:** Home, Atlas, Category, Tool Details, Compare.
2. **Domain/Content:** Categories, Tools, Languages, Sources, Content Documents, Versions.
3. **Data Access:** ממשק מוגדר לגישה לנתונים, שניתן להחליף בין Seed Data לבין DB בלי שכתוב UI.
4. **Knowledge Enrichment (עתידי):** Scheduler → Discover → Fetch → Verify → Draft → Human approval → Publish.
5. **Learning (עתידי):** Progress, quizzes, guided projects.
