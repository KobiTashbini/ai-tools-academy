## הרחבת מודלים והסקה — בחירה לימודית
נוספו 15 פרקים לפי בקשת המשתמש. חובה ללמוד: OpenAI/GPT, Claude, Gemini, Llama ו־Qwen, לצד Hugging Face שכבר קיים. כדאי להכיר: DeepSeek, Mistral, OpenRouter, Together AI, שלוש פלטפורמות הענן וכלי ההרצה, כולל Ollama שכבר קיים. חובה אינה הוראה להעמיק בכל API: לומדים אחד היטב ומשווים את האחרים באותו תרחיש.

קטגוריה 07 שומרת על מספור ושם קיימים, ומדריך הקריאה בה מבחין בין ספק/משפחה לפלטפורמת גישה/ענן. קטגוריה 08 מציגה כלי עבודה ומנועי הסקה; Llama ו־llama.cpp הם פריטים נפרדים. פרקי הענן נשארים ב־07 בלבד כדי לא ליצור רושם שנוספו קורסי MLOps או פיתוח סוכנים מלאים. המקורות הרשמיים שנפתחו תומכים בהגדרות ובדרכי הגישה; תרגילים, סדר קריאה והקבלות ל־.NET הם תוכן שלנו.

נשמרו שמות לזיהוי: Azure AI Foundry מופיע כ־Microsoft Foundry בתיעוד שנבדק; קישורי Vertex AI שנפתחו מפנים לתיעוד Gemini Enterprise Agent Platform. אין טענה שכל שירות היסטורי עבר שינוי זהה. לא נקבעו גרסאות מומלצות, מחירים או דירוגי ביצועים, ולא הורדו מודלים. תרגילי הספקים ניתנים להתחלה כתכנון חוזים ללא חשבון בתשלום. מקורות כרטיסי דגם ורישיונות חייבים להיבדק מחדש לפני בחירת דגם מסוים.

בהמשך להרחבה הושלמו 14 תאריכי השקה מתוך 15 פריטים חדשים; DeepSeek נשאר ללא תאריך מאומת. נוספו Stars ו־Forks ל־llama.cpp ול־vLLM ורוענן Ollama. לשלושת המנועים חושב GitHub Interest מקומי במדגם 08 נפרד; אין שינוי במדגם קטגוריה 02 ואין להשוות את ציוניהם. במשפחה/פלטפורמה ללא מאגר מייצג וב־LM Studio שאין לו כאן מאגר מלא של היישום נשמר הסבר מפורש במקום שימוש במאגר SDK כתחליף. פירוט ב־[METRICS.md](METRICS.md).

## סדר קריאה מומלץ
1. יסודות מודלי שפה: Tokens, ההבדל בין אימון להסקה, וחוזה פלט מול נכונות עסקית.
2. Codex: משימה, תנאי קבלה, Diff ובדיקות; אחריו Claude Code ו־Cursor להשוואת תהליכי עבודה.
3. MCP: ההפרדה בין יכולת עסקית לפרוטוקול שמנגיש אותה.
4. Microsoft Agent Framework: חיבור ל־C#/.NET, ולפניו תכנון לולאת כלים ידנית.
5. LangChain, Agents SDK ו־Pydantic AI; לאחריהם LangGraph ו־Temporal לניהול מצב והתאוששות.
6. n8n ו־Dify לתכנון אוטומציה ויישומי AI; LlamaIndex ו־Qdrant לאחזור ידע.
7. Langfuse למדידה והערכה. Ollama ו־Hugging Face להבנת דרכי הפעלת מודלים.
8. CrewAI ו־PyTorch כהרחבה אחרי שיש בסיס מתאים, בהתאם לתרגול הדרוש.

## תקן הפרקים
בקטלוג מוצגים כעת עדיפות הלימוד והנמקה קצרה לכל אחד מ־35 הפריטים. העדיפות מבוססת על הפרקים הקיימים וההנמקה נשמרת ב־`content/learning-guidance.json` עם תאריך סקירה. אלה המלצות פדגוגיות מותאמות לרקע המפתח ולמטרות האקדמיה; אין בהן טענה על נתח שוק, מספר משתמשים או דירוג תפוצה דינמי. מחקר תפוצה לפי מספר מקורות עדיין לא מומש.
כל פרק כולל דרישות קדם, עדיפות לימוד, לפחות חמישה סעיפי הסבר, דוגמה לימודית, תרגיל עם תוצר, תמיכת שפות או גבולות האימות שלה, חלופות וקישורים לפרקים נוספים. מקורות רשמיים נבדקו ב־2026-10-31.

האימות מכסה את הגדרת הכלי ואת היכולות המיוחסות למקור בעמוד. דוגמאות, הקבלות ל־.NET ושיקולי בחירה הם תוכן לימודי שלנו. לא בוצעו ניסויי השוואת ביצועים, אימות מחירים או בדיקת כל גרסת SDK. חלופות שמוזכרות בלבד אינן סקירה מאומתת שלהן. ההסברים אינם תחליף לדוגמאות קוד שנבדקו; מעבדות מעשיות יתווספו בשלבים הבאים.

## תחזוקת התוכן
`content/entries.json` מכיל את פריט MCP, עם גרסה משלו. `content/lessons.json` מכיל קבוצת 34 פרקים עם תאריך בדיקה, מצב פרסום וגרסה מפורשים. הרחבת אותו יום תועדה בגרסה 2; המקורות החדשים נפתחו בנפרד. `assemble-entries.mjs` ממפה אותם למודל המשותף לפני בדיקת התקינות. `content/category-guides.json` מכיל מדריכי קריאה לקטגוריות 07 ו־08. עריכת קבוצה דורשת בחינה מחדש של סטטוס האימות והגרסה; אין להוסיף מקורות שלא נבדקו ולהשאיר אותם מסומנים כמאומתים.

בעתיד נפצל קבוצות אם נדרש עדכון עצמאי בתאריכים שונים, ונוסיף תוכן Markdown וראיות ברמת טענה. הצעות מחקר אוטומטיות עתידיות יישמרו כטיוטות במסלול נפרד, עם אישור אנושי לפני פרסום.
