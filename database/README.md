# מסד PostgreSQL של האקדמיה

עודכן: 2026-10-31. פרויקט Supabase: ai-tools-academy, מזהה winnpnsmwkullbhrolan, מסלול Free, אזור eu-west-3.

## המבנה הפעיל
הסכמה academy מכילה טבלאות רגילות עם שדות מפורשים ומפתחות זרים. אין בה עמודות JSON בטבלאות ואין payload לעריכה. לכל נתון יש מקום פעיל אחד; View מחבר נתונים לקריאה בלי לשמור עותק נוסף. מפת השדות ב־[DATA_DICTIONARY.md](DATA_DICTIONARY.md).

הסכמה academy_import_archive מכילה את הייבוא המקורי ואת גרסאות התיאור הקודמות לצורך התאוששות בלבד. Trigger חוסם INSERT/UPDATE/DELETE/TRUNCATE בטבלאות הארכיון. אין קשרי FK מהארכיון לטבלאות הפעילות. הארכיון אינו גיבוי חיצוני ואינו מקור לעריכה שוטפת.

## קריאה נוחה
ב־Table Editor לבחור schema academy ואז catalog לתצוגה משולבת או entries לשדות הבסיס. catalog הוא View, לא עותק של הטבלאות. פרטי הפרק ב־entry_lessons, סעיפים ב־entry_sections והמלצות ב־learning_guidance.

```sql
select * from academy.catalog order by name;
select * from academy.entry_sections where entry_id='mcp' order by position;
select * from academy.entry_releases;
select * from academy.community_interest;
```

entry_documents הוא View טכני שמרכיב JSON מהטבלאות לצורך ייצוא ובדיקת התאמה. אין לערוך אותו כעותק תוכן נוסף. community_interest מחשב ציונים מהמדידות בתוך כל מדגם ומועד מדידה; לא שומרים ציון מחושב בנפרד.

## מיגרציות ובדיקות
המיגרציות 002–004 הוחלו ואומתו בענן. אין להריץ שוב 001 או initial-import.sql על הפרויקט הקיים.

- 001_catalog.sql ו־scripts/prepare-database.mjs: שלב הייבוא ההיסטורי, נשמר לשחזור ולבדיקות של התקנה חדשה בלבד.
- 002_normalize.sql: מעבר אטומי, ארכוב המבנה הישן, פיצול לשדות, אילוצים, תצוגות והרשאות.
- 003_merge_catalog_descriptions.sql: תיאור קטלוג פעיל יחיד. ב־7 פריטי הפיילוט נשמר התיאור הקומפקטי שכבר מוצג באתר; הנוסח הקודם בארכיון.
- 004_detach_archive.sql: הסרת View ארכיוני נגזר שאינו שומר נתונים וניתוק FK מהארכיון לנתונים הפעילים.
- verify_catalog.sql: שאילתות קריאה לבדיקת ספירות, התאמת כל התוכן לארכיון, חתימות, היעדר עמודות JSON בטבלאות והגנות הארכיון.

npm test מריץ PostgreSQL מקומי בזיכרון דרך PGlite: ייבוא, הגירות, השוואת כל הפרקים, מדדים ומדריכים, חסימת גישה ללא הרשאה, כתיבה לארכיון, קשרים שבורים והרצה חוזרת. נבדקת גם דרך חזרה. זה אינו תחליף לבדיקת הענן; בסבב זה בוצעו גם בדיקות SQL ישירות בענן.

## דרך חזרה
rollback_002.sql משמר את שני המבנים: מחזיר את המבנה המקורי ל־academy ומעביר את המנורמל ל־academy_normalized_rollback. הוא נעצר אם תוכן הפרקים השתנה; שינויים במדדים, מדריכים או נתונים אחרים מחייבים בחינה ויישוב ידני לפני החזרה. לא נמחקות סכמות או רשומות. נבדק מקומית בלבד, לא הופעל בענן. נדרשת הרשאת בעלים. אחרי דרך חזרה יש לבדוק מחדש את כל ההרשאות והצרכנים.

## מקור אמת ואבטחה
בתוך מסד הנתונים academy הוא המבנה הפעיל היחיד. האתר, מחקר הסוכן ורענון המדדים עדיין משתמשים בקבצים המקומיים — חיבורם למסד והחלפת מקור האמת טרם בוצעו. עד להחלפה אין להניח ששינוי ב־Supabase מתפרסם באתר או ששינוי קובץ מסתנכרן למסד.

RLS פעיל בכל הטבלאות; אין policies ציבוריות, חשיפת הסכמה ל־Data API או הרשאות חדשות. ה־Views הם security_invoker. אין מפתחות או סיסמאות בקוד. משתמשי קריאה/ייבוא מוגבלים וגיבוי חיצוני עדיין נדרשים לפני חיבור האתר. הארכיון המקורי ופקודות ההקמה אינם מערכת מלאה להיסטוריית עריכות עתידיות; מנגנון audit לעריכה מקוונת יתווסף עם ממשק העריכה.
