אנחנו מתחילים באפיון AI TOOLS Academy, לפני כתיבת קוד.

קרא קודם את הקבצים: AGENTS.md, PRODUCT_VISION.md, ARCHITECTURE.md, ROADMAP.md, AI_TOOLS_CONTEXT.md.

חשוב: יש לי פרויקט קודם ב-GitHub:
https://github.com/KobiTashbini/lingua-reader

הוא משמש פרויקט ייחוס (Reference Architecture) בלבד. בדוק את מבנה הקוד, גרסאות, API Routes, Supabase, Vercel, משתני סביבה מקומיים (שמות בלבד, לא ערכי סודות), הרצה מקומית ושיטת Deployment. אל תשנה שום דבר בפרויקט LinguaReader.

בפרויקט החדש אני רוצה להעריך שימוש באותה גישה טכנולוגית ובאותם ספקי ענן (Next.js, TypeScript, Vercel, Supabase) כי כבר עבדתי איתם. זו העדפה לבדיקה, לא הוראה מחייבת: אם לדעתך ASP.NET Core, Python Worker או גישה אחרת טובים יותר, הצג חלופה מנומקת.

בשלב הראשון הצג לי בעברית:
1. מה זיהית בפועל ב-LinguaReader ומה עדיין לא אומת.
2. השוואת אפשרויות התשתית ל-AI TOOLS Academy, כולל התאמה ל-V1 ולסוכנים מתוזמנים עתידיים.
3. המלצה על Stack עם יתרונות, מגבלות, עלויות/מורכבות ובדיקות נדרשות.
4. מפת המסכים: Home, Atlas, Category, Tool Details, Compare; כולל RTL תקין.
5. מודל נתונים ראשוני ל-12 הקבוצות, כלים, שפות, מקורות וגרסאות.
6. תוכנית פיתוח מדורגת וקריטריוני קבלה.
7. אילו החלטות צריך את אישורי לפני מימוש.

אל תתחיל לכתוב קוד, להתקין תלות, ליצור בסיס נתונים או משאבי ענן, לשנות סודות או לבצע Deployment. אל תבקש שאשלח מפתחות סודיים בצ'אט.
תחילה הצג תכנון ואמת איתי את ההחלטות.
