## הכרעה מרכזית

להוסיף פרק יסודות ו־Microsoft.Extensions.AI כגשר .NET קטן לפני מסגרת סוכנים; לתקן מידע גרסה/שפה ולספק בחירה בין stack אחד למסלול אחר. אין צורך ללמוד12 מסגרות כדי להבין סוכן. חמש תוספות מוצעות, שבע הרחבות ומדריך: **13 הצעות A02-01–A02-13**. Strands ו־Deep Agents הן העשרה להשוואת harness; A2A חשוב להיכרות כשיש סוכנים בגבולות שירות נפרדים. רמת חשיבות אינה הוכחת פופולריות או חובת התקנה.

## דוגמאות, יתרונות, חסרונות וחלופות — תכנון שלא הורץ

1. **יסודות ו־Extensions.AI:** שירות מלאי C# משותף מקבל בקשה, המודל מציע get_stock והיישום מאמת קלט והרשאה. הגדירו תקרת צעדים, cancellation, נתוני state ואישור לפני reserve_item. יתרון abstraction קטן הוא בדיקות פשוטות ותלות נמוכה; חסרון הוא אחריות שלכם על לולאה, persistence ו־retry. אין סיבה למסגרת רבת־סוכנים לכל שאילתת מלאי.
2. **MAF מול LangGraph:** אותו תהליך הצעת רכש עם pause לאישור וכשל אחרי side effect. בחרו MAF למסלול.NET ו־LangGraph להשוואת state/edges; checkpoint אינו בדיוק-once של SQL. יתרון framework הוא קוד תשתית חוזר; מחירו תלות API ותפעול/שפה. evals והרשאות נבדקות ביישום בכל בחירה.
3. **LangChain/OpenAI SDK/Pydantic:** השוו פלט DTO ותהליך tool אחד, לא ציון שיווקי. LangChain מספקת הרכבת loop/middleware; OpenAI SDK מנהלת run בתוך היישום; Pydantic מדגישה typed dependencies ומציעה חיבור למנוע durable. בחרו אחד, הצמידו model וגרסה, והשוו error/timeout/trace. שירות Python שנצרך מ־.NET אינו native SDK.
4. **CrewAI ו־Mastra:** CrewAI היא העשרה לדפוסי תפקידים, Mastra מסלולTS לצוות מוצר. תכננו researcher→reviewer בלבד אם שתי אחריויות באמת נדרשות; השוו לסוכן יחיד. יתרון הבחנה מפורשת בתפקידים/זרימה; חסרון coordination, עלות והגדלת surface של תקלות. רישוי Enterprise ונתוני זיכרון נבחנים לפני פריסה.
5. **Strands:** שירות Python אוTS מחזיר הצעת טיפול לקריאה בלבד ל־ASP.NET. בדקו limits/cancellation מול חלופת MAF אוSDK אחר; יתרון loop בתוךprocess וללא controlplane חובה, חסרון stack נוסף לקהל.NET ותלות ביכולות provider. קוד Apache2 אינו רישיון מודל או שירות AWS.
6. **Deep Agents:** משימת מחקר על קבצים סינתטיים, עם subagent אחד, directory מוגבל ותוצר JSON שהשרת מאמת. יתרון context/harness מוכן, חסרון הרשאות קבצים וקוד והגברת מורכבות. בחנו אם create_agent או graph קטן מספיק; אין חובת harness מעל כלLangGraph.
7. **A2A:** סוכן שירות רכש פונה לסוכן מלאי בשירות נפרד, תוך זיהוי זהות, skill וסטטוס task. יתרון interoperability בין שירותים/צוותים, חסרון auth, גרסאות וגבולות tenant. אם שתי הפונקציות באותו יישום, קריאת פונקציה אוREST עשויות להספיק. MCP מחבר כלי; A2A מחבר סוכן — הם יכולים להשלים זה את זה.

כל הדוגמאות לא הורצו; אין תוצאות איכות עברית, latency, עלות, אבטחה או התאוששות בפועל. אין טענה שהעברה אוטומטית בין agents פוטרת מאישור כתיבה או idempotency.

## סדר לימודי מוצע

ליבה: יסודות לולאה/הרשאה/מצב → agent ידני ב־C# עם SDK מודל או Extensions.AI → MAF לתרגיל .NET אחד → graph/checkpoint כהשוואה עם LangGraph → eval ו־trace ב־10. ההסתעפויות נבחרות לפי צורך: Python אחד מתוך Pydantic/LangChain/OpenAI SDK/Agno/ADK; TypeScript Mastra אוSDK מתאים; CrewAI/smolagents כהעשרה. Temporal כשיש תהליך ארוך ועצמאות worker, A2A כשיש גבול agent-to-agent, ו־Strands/Deep Agents להשוואת harness. אין חובה להתקין את כל הכלים.
