## השוואה מעשית ודוגמאות מוצעות שלא הורצו

- **יסודות:** בקשת ציוד נקלטת ב־webhook ומקבלת מזהה עסקי. בדקו בקשה כפולה, כשל אחרי ביצוע פעולה ולפני ACK, timeout ואישור מנהל. חוקי SQL והרשאות נשארים בשירות; חילוץ טקסט חופשי הוא שלבAI אופציונלי.
- **n8n:** HTTP Request מפעיל API ASP.NET לפתיחת טיוטה ורק לאחר אישור מבצע שמירה. יתרון: connector/flow מוריד קוד דבק; חסרון: סודות, retries ואחסון execution data דורשים בקרה. Code node הוא JS/Python ולא C#. SUL/EE אינם רישיוןMIT; ההחלטה לאירוח מסחרי/white-label נבדקת מול הרישיון והמהדורה, לא מראה editor בלבד. ה־FAQ הרשמי המעודכן06/10 מתייחס גם לעריכת workflow דרךAPI/MCP/agent, ולכן ״הלקוח לא רואה UI״ אינו היתר כללי. מקורFAQ הוא פרשנות ספק; LICENSE הוא נוסח התנאים.
- **Temporal:** תהליך.NET ממתין יום לאישור ומבצע Activity של הזמנה; ה־Worker נכשל וחוזר. היתרון הוא עמידות orchestration; החסרונות הם היסטוריית אירועים, דטרמיניזם, שירות ו־Workers לתפעול. תוצאה שנשמרה בתהליך אינה מונעת side effect כפול אצל ספק חיצוני; נדרש idempotency key. .NET SDK רשמי MIT, server/cloud תנאים נבדקים בנפרד. הרחבת Workflow Streams מתועדת Public Preview, עם APIs/config שעלולים להשתנות, והחל מ־SDK1.20.0; אין להחיל Preview על כל Temporal. אין טענת ״לא יכול להיכשל״ מתוך slogan ספק.
- **Make:** webhook מ־.NET יוצר scenario של בדיקה→טיוטה→אישור. יתרון: SaaS חזותי ללא ניהול שרת; חסרון: עלות, מכסות, נתונים בתור ותלות שירות. instant webhooks מעובדים במקביל כברירת מחדל; Process data in order הוא אפשרות שיש לבחור כשנדרש סדר. Make Code תומךJS/Python במסלולים בתשלום; אינו הרצת C# או הבטחת בידוד אבטחה מוחלט. סדר אינו idempotency.
- **Zapier:** Zap מסנכרן אישור ממערכת צד שלישי ל־API.NET. יתרון: מחזור פיתוח connector מנוהל; חסרון: runtime/rate limits ותלות connections. Code JS/Python ו־SDK לפעולותJS אינם SDK.NET. מסמך migration מ־Zapier Functions ל־Code הוא שינוי רכיב, לא הפסקת כל Zapier. אין מספר apps או ״users״ שנלקח מהשיווק כמדד adoption.
- **Activepieces:** אותו flow נבדק בפריסה עצמית עם API.NET. יתרון: coreMIT מהווה חלופת רישוי; חסרון: EE/cloud features מסחריות ותפעול PostgreSQL/Redis/Workers לפי התצורה. self-host אינו no-egress כש־piece פונה ל־SaaS. אין שימוש בטענת SOC2 כללית או הבטחת שמירת מידע ללא בדיקת מהדורה.
- **Windmill:** C# script קורא נתוני מחסן ומורכב ל־Flow עם שלב אישור; יש להפריד סודות מקלט. יתרון: קוד.NET ו־scripts versions משתלבים בתהליך אוטומציה; חסרון: workers, timeout/cache, רישוי ותפעול אינם זהים ל־Temporal replay. LICENSE מבחין AGPL3 לליבה, קוד Enterprise מסחרי, וכמה clients/OpenAPI ב־Apache2. אין הבטחת רישיון permissive לכל המוצר או צורך ללמוד גם אותו וגם כלי חזותי.
- **Power Automate:** cloud flow מאשר בקשת רכש דרךconnector; desktop flow מיועד רק למערכת ללאAPI. יתרון: משתלב בסביבת Microsoft מוכרת; חסרון: הרשאות/רישוי connectors ועמידותUI. custom connector יכול להריץ C# טרנספורמציית request/response תחת מגבלות, לרבות.NET Standard2.0 ו־namespaces נתמכים; אינו שירות.NET חופשי. יש סתירת תיעוד על מגבלת זמן בין guide ו־FAQ/define-blank, לכן אין לפרסם timeout יחיד בלי אימות ייעודי. זה אינו Copilot Studio או Agent Framework.

## כיוונים שנדחו וגבולות גישה

- **Node-RED:** נפתח [About הרשמי](https://nodered.org/about/): flow-based runtime ב־Node.js עם functionsJS, מתאים במיוחד להקשרevent-driven/edge. נדחה מחבילת הליבה כי אין צורך באוטומציה נוספת ללא דרישתIoT/edge; לא מסומן נטוש. לא הושלם audit אבטחה/רישוי/תוספים מלא.
- **Azure Durable Functions / Durable Task:** נפתח [overview הרשמי](https://learn.microsoft.com/en-us/azure/durable-task/durable-functions/durable-functions-overview), עם.NET C# רשמי ו־orchestrator/activity/entity. זו חלופת התמחותserverless חשובה ל־Temporal, אך מוסיפה hosting/storage והרחבתAzure; מומלץ המשך כשהקשרAzure קונקרטי. אין ליצור זהות נפרדת לכל rename או SDK בלי סקירה.
- **Camunda/BPMN, Pipedream ו־Azure Logic Apps:** כיווני גילוי להמשך לפי enterprise/process/code integration. לא הושלם להם audit ייעודי בריצה זו ולכן אינם הצעות לאישור ולא טענת נחיתות.
- **Composio09 ו־Copilot Studio06:** כבר בקטלוג עם תפקידים נבדלים; יש להפנות ולא ליצור כפילות03. חיבורagent בתוךworkflow אינו משנה כל אוטומציה ל־agent framework.

גישה ל־n8n `/sustainable-use-license/` החזירהPageNotFound; הוחלפה ב־LICENSE הרשמי וב־Help Center פעיל. תוצאת mirror לא רשמית הוחרגה. דף Microsoft Learn מציג הודעתauthorization בתבנית אך גוף התוכן נגיש. לא בוצעו התקנות, accounts/trials בתשלום, קריאותמודל, בדיקתlatency או בדיקתUI. רישוי מתואר כעובדת מקור ולא ייעוץ משפטי או היתר שימוש פרטני.
