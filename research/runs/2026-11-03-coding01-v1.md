## הכרעה ומסגרת

הפערים העיקריים: מתודולוגיית פיתוח סוכני כפרק יסוד, GitHub Copilot כנתיב Visual Studio/.NET, והבחנה בין CLI, IDE ומסירת משימה לריצה. אין חובה ללמוד כל assistant או להחליף עורך כדי ללמוד AI-assisted development. מומלץ לתרגל מוצר אחד לעומק ולהשוות מוצר נוסף על אותה משימה.

גילוי בוצע בחמש קבוצות: coding agent permissions/sandbox, native Visual Studio integration, open-source/provider-choice, terminal/Git workflows, ושינויי זהות Google/Windsurf. ארבע פעימות חיפוש ממוקדות הובילו לפתיחת מסמכי מוצר, security/privacy, LICENSE, קישורי מעבר וסקר רשמי. אומתו שינויים מהותיים שאינם ניכרים משמות מוכרים: Windsurf הפכה Devin Desktop; Gemini CLI נותרת במסלולים מסוימים אחרי מעבר הצרכנים ל־Antigravity; Roo Code repo מאורכב. אין להעתיק רשימת2025 כאילו היא רשימת כלים פעילים2026.

## תמיכת C#/.NET, רישוי ופרטיות

בקטגוריה זו שפת המאגר שעליו עובדים אינה שפת SDK של המוצר. Codex/Claude Code/Cursor/Cline/Antigravity/Devin יכולים להציע שינוי בקוד C#, אך הרצת dotnet build/test מחייבת SDK, dependencies וכלים מתאימים בסביבה שנבחרה. אין מכאן SDK .NET מקומי של כל assistant או שוויון debugging בין עורך מבוסס VS Code לבין Visual Studio.

**Codex:** להוסיף מפורשות ש־sandbox מגביל filesystem/network ואישור קובע מתי ניתן לצאת מגבול; אישור פקודה אינו הוכחה לתוצאה נכונה. Windows, WSL2, Linux ו־macOS משתמשים במנגנונים שונים לפי המסמכים. CLI Apache2 אינו רישיון שירות/מודל. להימנע מהצגת danger-full-access כהמלצת התחלה. [Official OpenAI documentation](https://learn.chatgpt.com/docs/agent-approvals-security). קישור codex/security נפתח ונמצא כ־Codex Security scanner; זו הבחנת מוצר, לא סיבת Lifecycle.

**Claude Code:** Manual מתחיל בקריאה; modes אחרים והרשאות שמורות יכולים לאפשר עריכה/פקודות. Working-directory prompt אינו בידוד OS לפקודת Bash שאושרה; sandbox מוסיף אכיפה. consumer training תלוי setting, בעוד מסלולים מסחריים כפופים למדיניות נפרדת/opt-in. אין להציג repo התיעוד/תוספים כקוד המקור המלא או רישיון לכל המוצר. [Security](https://code.claude.com/docs/en/security), [Data](https://code.claude.com/docs/en/data-usage).

**Cursor:** שינויים לקבצי workspace עשויים להישמר בלי אישור; auto-reload עשוי להריץ קוד לפני סקירה. Privacy Mode משנה שימוש לאימון אך קיימים חריגי abuse retention; בקשות עם API key פרטי עדיין עוברות backend. לא לטעון ״לא עוזב מחשב״. checkpoint הוא נוחות מקומית, לא Git. [Agent security](https://cursor.com/docs/agent/security), [Data use](https://cursor.com/data-use).

**Copilot:** Visual Studio agent mode מתועד מ־VS2022 17.14+, ונתיב chat חדש מ־VS2026 18.11 הוא בחירה נפרדת. המטריצה מסמנת supported/preview/closing לפי IDE, ולכן פרסום יכולת ללא IDE/version אינו מספיק. המוצר מסחרי; רישיונות SDKs/תוספים אינם היתר self-host לכל Copilot. לא בוצעה סקירת מחיר/חשבון או רישוי קוד שנוצר. [Microsoft](https://learn.microsoft.com/en-us/visualstudio/ide/copilot-agent-mode?view=visualstudio).

**Cline:** core TypeScript, Apache2, בחירת ספק אינה מבטיחה data locality. Auto Approve לפי קטגוריות; README שיווקי ״כל פקודה דורשת אישור״ אינו נכון לכל תצורה. סיווג safe מבוסס model flag ולא fixed allowlist לפי המסמך; checkpoints אינם הרשאה. [Auto Approve](https://docs.cline.bot/features/auto-approve).

**Antigravity:** deny/ask/allow ו־sandbox הם מסלולים שונים. Auto preset של האפליקציה Preview v2.23.0+ אינו זמינות עסקית גורפת; CLI auto Preview מתועד בגרסאות/OS אחרות. במימוש קטלוג יש לציין Preview ברמת התכונה ולא לסמן את כל המוצר Preview. אין טענת SDK C# מאומת. [Permissions](https://antigravity.google/docs/permissions).

**Devin Desktop:** alias Windsurf נשמר; acquisition announcement14/07/2025 הוא אירוע רכישה, לא יום השקה או rebrand. תיעוד Cascade מסומן legacy אך מוצר Desktop פעיל במקורות; אין להכריז ״Windsurf discontinued״ ללא ראיית הפסקה מתאימה. רישוי ושירותים מסחריים; לא מאגר פתוח מייצג. [Rename](https://devin.ai/blog/windsurf-is-now-devin-desktop).

**Aider:** Python runtime, עריכת C# עם repo map נתמכת לפי טבלת השפות. ברירת המחדל כוללת auto-commit ושמירת dirty changes ב־Git; לפני תרגיל עם אישור Commit נפרד יש לבחור no-auto-commits/no-dirty-commits, ולא לפרש תיעוד tool כרשות לבצע Commit. מודל/provider ותנאי השירות נפרדים מ־Apache2. [Git](https://aider.chat/docs/git.html).

**Gemini CLI:** README נוכחי מציג Enterprise Code Assist ומפנה צרכנים ל־Antigravity ב־18/06/2026. הודעת Google19/05 מפרטת גם המשך paid Gemini/AgentPlatform API keys; לכן אין לכתוב ״enterprise account בלבד בכל מסלול״ או ״הופסק״. README מזהיר גם שאינו optimized ל־Gemini4+ בעוד ההודעה מבטיחה updates לארגונים: יש להציג תלות מסלול ולא הבטחת model parity. הקוד Apache2 אינו הרשאת שימוש בשירות. [README](https://github.com/google-gemini/gemini-cli), [Announcement](https://developers.googleblog.com/an-important-update-transitioning-gemini-cli-to-antigravity-cli/).

התרחיש המשותף: באג ולידציה בטופס React וב־ASP.NET endpoint. כתבו reproduction, שלושה תנאי קבלה וגבולות כתיבה. assistant אחד משנה patch מוגבל; בדקו גם בקשה ישירה לשרת, הרשאה חסרה, שדה חסר ו־regression. סקרו diff לפני שמירה. השוו assistant נוסף באותו checkout נפרד ובאותם תנאים; מדדו תיקונים נדרשים, איכות בדיקות ועלות/זמן בפועל בלי להסיק תוצאה מראש.
ל־Copilot התמקדו ב־Visual Studio; ל־Cline בדקו תצורת approval/provider; ל־Aider מנעו auto-commit לא מורשה; ל־Antigravity הפרידו Preview/OS; ל־Devin Desktop השוו local/cloud ותיעוד audit בלי להניח שכל בקרת ענן זהה. התרגילים לא הורצו; אין benchmark עברית/איכות קוד/latency או חשבון בתשלום שנבדק.
