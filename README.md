# AI TOOLS Academy

פלטפורמת ידע בעברית. השלב הנוכחי כולל בית, אטלס 12 קטגוריות, עמודי קטגוריה ומבוא ראשון ל־MCP עם מקור ותאריך בדיקה. יתר הקטגוריות מציגות מצב ללא תוכן. חיפוש והשוואה עדיין אינם ממומשים.

## הפעלה מקומית

נדרש Node.js 24 LTS עם npm. מתוך תיקיית הפרויקט:

```powershell
npm ci
npm run dev
```

פותחים http://localhost:3000 . עוצרים עם Ctrl+C. אין צורך ב־env, במפתחות או במסד נתונים.

## בדיקות

```powershell
npm run typecheck
npm test
npm run build
npm run start
```

יש לעצור שרת dev לפני הפעלת start באותו פורט. build אינו בדיקה חזותית. לבדיקה ידנית: ניווט לבית ולאטלס, קישור ״איך נלמד״, מקלדת Tab וקישור דילוג לתוכן, תצוגת טלפון, עברית ושמות באנגלית ללא גלישה אופקית.

בחלון נוסף, כשהשרת פועל: `npm run test:smoke`. הבדיקה מכסה את הבית, האטלס, 12 הקטגוריות, MCP ונתיבים חסרים. לפורט אחר מגדירים `SMOKE_BASE_URL`.

## מבנה התוכן

`content/categories.json` שומר את הטקסונומיה הקבועה; `content/entries.json` שומר פריטי ידע ומקורות. `src/domain/knowledge.ts` מגדיר טיפוסים, ו־`src/data/knowledge.ts` מספק גישה לתוכן מפורסם בלבד. בדיקת תקינות מופעלת בזמן טעינת הנתונים; תוכן פגום מכשיל את הבנייה. המודל ראשוני, טרם פוצל למסמכי Markdown ולראיות ברמת כל טענה.
