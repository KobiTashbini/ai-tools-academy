# AI TOOLS Academy

שלד מקומי של פלטפורמת ידע בעברית. השלב הנוכחי כולל בית, ניווט ומציין מקום לאטלס; חיפוש, השוואה ותוכן עדיין אינם ממומשים.

## הפעלה מקומית

נדרש Node.js 24 LTS עם npm. מתוך תיקיית הפרויקט:

```powershell
npm ci
npm run dev
```

פותחים http://localhost:3000 . עוצרים עם Ctrl+C. אין צורך ב־env, במפתחות או במסד נתונים.

## בדיקות

```powershell
npm run typecheck
npm run build
npm run start
```

יש לעצור שרת dev לפני הפעלת start באותו פורט. build אינו בדיקה חזותית. לבדיקה ידנית: ניווט לבית ולאטלס, קישור ״איך נלמד״, מקלדת Tab וקישור דילוג לתוכן, תצוגת טלפון, עברית ושמות באנגלית ללא גלישה אופקית.

## רציפות עבודה

קוראים תחילה AGENTS.md, PROJECT_STATUS.md, TASKS.md ו־DECISIONS.md. אין פריסה או משאבי ענן ללא אישור נפרד.
